# Executive Summary

## Q: What problem does this solution solve?

### Answer

This solution enables users to ask natural language questions against private documents using Retrieval Augmented Generation (RAG). Instead of relying solely on model knowledge, the system retrieves relevant document content and injects it into the prompt, producing grounded and explainable responses.

---

## Q: Why did you choose RAG instead of fine-tuning?

### Answer

Knowledge changes more frequently than models. RAG allows us to update documents without retraining models, reduces operational overhead, supports source attribution, and generally lowers costs compared to continuous fine-tuning.

# Retrieval

## Q: What are embeddings?

### Answer

Embeddings are numerical vector representations of text that capture semantic meaning. Similar content generates vectors that are close together in vector space.

---

## Q: Why is chunking needed?

### Answer

Entire documents are usually too large and contain multiple topics. Chunking improves retrieval precision by allowing searches against smaller and more focused content.

---

## Q: What is Top-K retrieval?

### Answer

Top-K retrieval returns the K most similar chunks for a user's query based on vector similarity scores.

---

# Prompt Engineering

## Q: What is a prompt?

### Answer

A prompt is the complete set of instructions and context sent to the model, including system instructions, conversation history, retrieved content, and the current question.

---

## Q: How does prompt engineering reduce hallucinations?

### Answer

Prompt engineering introduces grounding instructions and relevant context, encouraging the model to answer using retrieved evidence rather than assumptions.

---

# Memory

## Q: Are LLMs stateful?

### Answer

No. LLMs are stateless. Conversation memory is achieved by including previous interactions in subsequent prompts.

---

## Q: Memory vs Retrieval?

### Answer

Retrieval provides document knowledge. Memory provides conversation context.

---

# Streaming

## Q: Why use SSE?

### Answer

SSE is ideal for one-way server-to-client token streaming and provides a ChatGPT-like experience with lower complexity than WebSockets.

---

## Q: Does streaming make responses faster?

### Answer

It improves perceived performance because users see content immediately, although actual generation time may remain unchanged.

---

# Evaluation

## Q: What is grounding?

### Answer

Grounding means that generated answers are supported by retrieved evidence.

---

## Q: What is a hallucination?

### Answer

A hallucination is unsupported or incorrect information generated by the model.

---

## Q: Why evaluate a RAG system?

### Answer

Evaluation provides measurable evidence of quality across retrieval, grounding, answer correctness, and system performance.

---

# Advanced RAG

## Q: What is Agentic RAG?

### Answer

Agentic RAG extends traditional RAG by allowing systems to plan, evaluate, retrieve additional information, and dynamically decide the next action.

---

## Q: What is query rewriting?

### Answer

Query rewriting transforms user questions into retrieval-optimized queries to improve retrieval quality.

---

## Q: What is re-ranking?

### Answer

Re-ranking reorders retrieved chunks using deeper relevance analysis before they are sent to the model.

---

# Production

## Q: How would you scale this system?

### Answer

Through stateless APIs, load balancing, vector database scaling, caching, model gateways, and observability.

---

## Q: How would you reduce costs?

### Answer

Caching, prompt optimization, dynamic Top-K retrieval, context compression, and model routing.

---

# Security

## Q: What is prompt injection?

### Answer

Prompt injection is an attempt to manipulate model behavior through malicious instructions included in user inputs or retrieved documents.

---

## Q: What is indirect prompt injection?

### Answer

Indirect prompt injection occurs when malicious instructions are embedded inside retrieved content and influence model behavior.

---

# Lessons Learned

## Q: What was the biggest lesson?

### Answer

Retrieval quality and evaluation typically impact answer quality more than model size alone.
