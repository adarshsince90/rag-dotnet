# Environment & System Configuration

This document records the baseline environment versions, runtime ports, AI model parameters, and secrets management configuration.

## Toolchain & SDKs

| Tool | Recommended / Minimum Version | Notes |
|---|---|---|
| **.NET SDK** | `.NET 10.0` (or preview SDK targeting `net10.0`) | Required for API, Application, Domain, Infrastructure, and CLI |
| **Git** | `>= 2.50` | Version control |
| **Docker Engine** | `>= 24.0` (with Docker Compose) | Runs Qdrant & Ollama services |
| **Ollama** | Latest container via Docker or native binary | Serves local embeddings & chat models |

## Infrastructure & Runtime Ports

| Service | Container Image | Port / URL | Description |
|---|---|---|---|
| **RagDemo API** | Local Process | `http://localhost:5000` | ASP.NET Core Minimal API & Static Chat UI |
| **Scalar API Docs** | Integrated | `http://localhost:5000/scalar` | Interactive OpenAPI documentation |
| **Qdrant Vector DB** | `qdrant/qdrant:latest` | `http://localhost:6333` (Dashboard: `/dashboard`) | Vector database & metadata storage |
| **Ollama Engine** | `ollama/ollama:latest` | `http://localhost:11434` | Local LLM and Embedding server |

## Configured AI Providers & Models

| Provider | Type | Model Name | Dimensions / Context | Config Key |
|---|---|---|---|---|
| **Ollama (Embeddings)** | Local | `nomic-embed-text` | 768 dimensions | `local` |
| **Ollama (Chat)** | Local | `gemma2:2b` | 2B parameters | `local` |
| **Groq (Chat)** | Cloud API | `llama-3.3-70b-versatile` / `llama3-8b-8192` | Cloud LLM | `groq` |

### Setting Secrets for Cloud Providers
```bash
dotnet user-secrets set "Ai:Providers:groq:ApiKey" "gsk_your_key_here" --project src/RagDemo.Api
```
