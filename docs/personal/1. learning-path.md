What is RAG?

RAG = Retrieval Augmented Generation

Without RAG:

User
  ↓
LLM
  ↓
Answer


The LLM only knows what it learned during training.

Example:

What is Adarsh's employee ID?


ChatGPT doesn't know.

With RAG:

User Question
      ↓
Retriever
      ↓
Relevant Documents
      ↓
LLM
      ↓
Final Answer


Example:

Question:
What is Adarsh's employee ID?

Retriever finds:
EmployeeInfo.pdf

LLM receives:

Question:
What is Adarsh's employee ID?

Context:
Employee ID = 12345

Answer:
12345


The LLM is answering using your private knowledge.

Step 4 - Chunk The Text

What is chunking?

Large files:

100 pages


LLMs cannot efficiently process huge documents.

We split them.

Example:

Chunk 1
Nagarro is a digital engineering company.

Chunk 2
Nagarro was founded in 1996.

Chunk 3
Headquarters are in Germany.


Simple service:

public class ChunkService
{
    public List<string> CreateChunks(string text)
    {
        return text
            .Split(".", StringSplitOptions.RemoveEmptyEntries)
            .Select(x => x.Trim())
            .ToList();
    }
}

Step 5 - Retrieval

For now use keyword search.

public class RetrievalService
{
    public string Retrieve(
        string question,
        List<string> chunks)
    {
        return chunks
            .FirstOrDefault(c =>
                question
                    .ToLower()
                    .Split(' ')
                    .Any(word =>
                        c.ToLower().Contains(word)))
            ?? "No match";
    }
}

Question:

Where is Nagarro headquartered?


Returns:

Headquarters are in Germany

Limitations of Phase 1

Keyword search fails.

Question:

Where is Nagarro based?


Document:

Headquarters are in Germany


No matching words.

Retrieval fails.

This is why embeddings exist.

Phase 2 - Add Embeddings

Instead of storing text:

[
 "Nagarro founded in 1996"
]


Store vectors:

[
 [0.12, 0.44, 0.90 ...]
]


These numbers represent semantic meaning.

Example:

Germany
Berlin
German
Headquarters
Located
Based


Their vectors become mathematically similar.

So:

Question:

Where is Nagarro based?


still finds:

Headquarters are in Germany
