# Cosine Similarity

## Purpose

Measure similarity between two vectors.

Question Vector
vs
Chunk Vector

---

## Formula

Cosine Similarity

=
Dot Product

/
(Magnitude A × Magnitude B)

---

## Interpretation

1.0

Very Similar

0

Unrelated

-1

Opposite Direction

---

## Learning

Cosine similarity is a ranking signal rather than an absolute confidence score.

Relative ranking is often more important than the numeric value itself.
