# Project Vision

## Objective

Build a Retrieval-Augmented Generation (RAG) application using .NET 10 while learning every core concept incrementally from first principles.

The application will evolve through small iterative sprints, beginning with simple keyword retrieval and gradually introducing embeddings, vector search, PDF processing, conversational memory, evaluation mechanisms, and production-grade architecture.

## Learning Philosophy

- Learn one concept at a time.
- Avoid unnecessary frameworks in early stages.
- Prioritize understanding over tool usage.
- Introduce complexity only when a limitation is encountered.
- Every new component should solve a real problem observed in the previous sprint.

## Final Target Capabilities

- PDF ingestion
- Text extraction
- Text preprocessing
- Chunking
- Embedding generation
- Vector storage
- Similarity search
- Open-source language model integration
- Conversational memory (last 4 turns)
- Automated evaluation
- Source attribution
- Extensible architecture

## Architecture Principles

- SOLID principles
- Dependency inversion
- Implementation behind interfaces
- Replaceable infrastructure components
- Testability
- Incremental evolution

## Success Criteria

A developer should be able to understand every major component of a modern RAG application by examining the evolution of the project from Sprint 0 through the final implementation.
