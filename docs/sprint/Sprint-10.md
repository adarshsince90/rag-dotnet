# Sprint 10 - Interactive Console Client

## Goal

Provide an interactive command-line interface
for chatting with the RAG application.

## Achievements

- Created RagDemo.Cli project
- Integrated Spectre.Console
- Added streaming response handling
- Added retrieval diagnostics visualization
- Added generation diagnostics visualization
- Added conversation management commands
- Improved user experience for demos

## Commands

/new

Creates new conversation

/exit

Exit application

## Benefits

- Easier testing
- Demo-friendly
- Works without browser UI
- Useful during development
