🏛️ Clean Architecture Layers & Boundaries

Strict Dependency Inversion ensures core business domain models remain independent of AI models and vector databases.

RagDemo.Domain Core Enterprise
Contracts, entities, evaluation records, and retrieval domain models.
Key Interfaces: IChatCompletionService, IVectorStore, IRetriever, IEmbeddingGenerator, IConversationMemory
Rule: Zero external dependencies. Cannot reference Application, Infrastructure, or Api.
RagDemo.Application Use Cases & Prompts
Pipeline coordination, QueryClassifier, RagPromptBuilder, and evaluation test runner.
Responsibility: Orchestrates ingestion and query pipelines. Implements grounding barrier.
Dependencies: References only RagDemo.Domain.
RagDemo.Infrastructure Adapters & I/O
Ollama, Groq API, Qdrant client, PdfPig extractor, CharacterChunkingStrategy.
Responsibility: Concrete I/O adapters. Network calls, vector indexing, disk persistence.
Dependencies: References RagDemo.Domain.
RagDemo.Api & Cli Entry Points
ASP.NET Core Minimal APIs, SSE streaming endpoints, interactive CLI terminal.
Responsibility: Dependency Injection root, HTTP endpoints (/chat/stream, /evaluation/run), SSE serialization.

⚡ Core System Hallmarks

  • Zero Framework Lock-in: Built from fundamentals in C# without LangChain or Semantic Kernel abstractions, providing 100% control over retrieval dynamics.
  • 1000 / 200 Character Chunking: Validated against deep learning papers (629 chunks across Attention Is All You Need and BERT) for optimal recall without token fragmenting.
  • Strict Grounding Contract: Prompt engineering strictly constrains the LLM to output: "I could not find the answer in the provided documents." when context is insufficient.
  • 4-Turn Sliding Conversational Memory: Thread-safe in-memory cache retaining recent dialogue history to rewrite ambiguous follow-up questions.
  • Real-Time SSE Token Streaming: IAsyncEnumerable<string> pipeline streaming tokens directly to web and CLI clients with sub-100ms time-to-first-token.
